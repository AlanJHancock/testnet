⚡ SynQ Compiler Benchmark

Three-way comparison: in-browser WASM · server loopback (pure compile) · full HTTP round-trip

What each column measures:
WASM The SynQ compiler running as a WebAssembly module inside your browser. No network. This is what the IDE uses for instant feedback.
Loopback The same native Rust binary on the server, timed server-side in nanoseconds via /synq/bench-compile. No PQC signing, no HTTP overhead — pure parse + codegen time.
HTTP A real POST /synq/compile including nginx, TLS, Axum routing, PQC attestation signing, and the network round-trip from your browser.

Why it matters: WASM vs Loopback shows the JIT penalty of running Rust compiled to WASM in the browser. Loopback vs HTTP isolates the network + signing overhead. All three compile identical source and produce identical bytecode.
