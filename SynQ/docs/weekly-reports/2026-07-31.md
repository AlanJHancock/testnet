- Full encoder/decoder in `synq-server/src/sqb.rs` with ACTS-VM conformance annotations
- CompileResponse now includes base64-encoded `sqb` field
- IDE green download button — shows file size after compile, hidden on clear

- AegisCall (0x8F) now uses `dispatch_deterministic()` path

- `expr_to_string()` helper surfaces runtime expression values in reverts (e.g. `VaultError::InsufficientBalance(balance)`)
- AEG1 cost model wired into VM handler with deterministic bounds
