## 2. IR Builder Gap Closure

### Missing Builtins
- **String builtins** (`str_len`, `str_concat`, `str_eq`): IrOp variants and lower.rs existed but builder routing was missing — fell through to user-defined function path and failed
- **Authority builtins** (`authority_envelope`, `authority_require`, `authority_identity`): Same pattern — IrOp variants (LoadAuthority, AuthRequire, AuthIdentity) and lowering existed but builder match block was missing
- **Contract name in error messages**: Source signing endpoint reported "Codegen error" but actually calls `compile_ir()` — renamed to "Compilation error" and includes contract name

### Runtime Error Attribution
- VM `call_function` now wraps `RuntimeError` and `Reverted` errors with the executing function name
- Example: `Runtime error: getBoxSizeY: TupleGet: not a Tuple`
- Structured errors (StepLimitExceeded, etc.) pass through unchanged

## 3. StructValue Contract — End-to-End

### Struct/Tuple Parameter Expansion
- Server returns `struct_defs` in CompileResponse (name + fields with types)
- IDE expands struct-typed params (Point, Rect) into sub-field inputs (x, y) instead of single text field
- IDE expands anonymous tuple types `(u256, u256)` into sub-field inputs by arity
- Server accepts comma-separated strings (`"10, 20"`) and JSON arrays (`[10, 20]`) as Tuple values
- Server rejects single-value args for tuple-typed params (prevents `I32(42)` instead of `Tuple(42, 99)`)

- `Value::Tuple` serialized as nested arrays in state handler (previously fell through to null)

### Contract Improvements

- Added `@effects(corner)` declaration and `require(initialised, ...)` guard to `setCorner`
- Verified: `setCorner` fails before `init()`, succeeds after, state correctly shows `corner: [42, 99]`

### IDE UX Polish

## 4. Solidity → EVM Verification (New Feature)

### /verify-sol Endpoint
- Takes Solidity source (+ optional contract name), compiles with Foundry (`forge build`)
- Returns: `success`, `evm_bytecode`, `warnings`, `errors`, `forge_version`
- Foundry v1.7.1 installed on server (forge, cast, anvil)

### Transpiler Fixes for EVM Compatibility
- **Memory placement**: `string` and `bytes` no longer get `memory` in state variable declarations — only in function params, returns, local vars, events, errors, and constructors
- **String builtins mapped**: `str_concat` → `string.concat()`, `str_eq` → `keccak256(bytes(a)) == keccak256(bytes(b))`
- **Caller casting**: `caller` → `uint256(uint160(msg.sender))` for compatibility with u256-keyed mappings (SynQ uses u256 for address-like keys)

### IDE SOL Verify Badge
- `solVerifyBadge` in toolbar next to existing VERIFY/L3/GAS/STEP badges
- Auto-calls `/verify-sol` after successful compile with transpiled Solidity
- Green ✓ with EVM bytecode size (e.g., `✅ SOL → EVM 4482B`) or red ✗ with errors
- Tooltip includes full Foundry output (version, warnings, errors)

### Verified Contracts
- **StructValue**: 2,356 chars Solidity → 4,482 chars EVM bytecode, 0 warnings
- **ComprehensiveToken**: 8,584 chars Solidity → builds clean, 0 warnings
